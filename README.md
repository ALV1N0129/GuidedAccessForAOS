# 사용법 유도 for Android (GuidedAccessForAOS)

iOS의 **손쉬운 사용 › 사용법 유도(Guided Access)** 를 안드로이드에서 구현한 앱입니다.
아이에게 폰을 건네주거나, 매장·전시용 기기를 한 개의 앱에 고정할 때 사용합니다.

## 기능 (iOS 사용법 유도와 대응)

| iOS | 이 앱 |
| --- | --- |
| 측면/홈 버튼 세 번 클릭으로 시작·종료 | **볼륨 내리기 버튼 빠르게 세 번** (또는 접근성 버튼/단축키) |
| 한 개의 앱에 고정 | 다른 앱·홈 화면·최근 앱으로 나가면 즉시 가리고 원래 앱으로 되돌림, 알림창 자동 닫기 |
| 화면에 동그라미를 그려 터치 차단 | 앱 화면 위에서 **사각형 영역을 드래그**해서 차단 (이동·크기 조절·삭제) |
| 옵션 › 터치 끄기 | 화면 전체 터치 차단 |
| 옵션 › 볼륨 버튼 | 볼륨 버튼 차단/허용 |
| 옵션 › 시간 제한 | 1분 ~ 3시간, 1분 전 알림, 종료 시 화면 잠금 |
| 암호로 종료 | 4~8자리 숫자 암호 (5회 틀리면 30초 잠금, 솔트+해시 저장) |
| 앱마다 설정 기억 | 앱별로 영역·옵션 저장 |
| 재시작하면 해제 | 기본은 동일, 설정에서 '재시작 후에도 유지' 가능 |

추가로, 이 앱을 **기기 소유자(Device Owner)** 로 지정하면 안드로이드의 LockTask(키오스크 모드)를
이용해 홈·최근 앱·알림창을 시스템 수준에서 완전히 잠급니다. (선택 사항)

## 사용 방법

1. APK를 설치하고 앱을 엽니다.
2. **접근성 설정 열기** → 설치된 앱 › **사용법 유도** 를 켭니다.
   - Android 13 이상에서 APK로 직접 설치했다면 '제한된 설정' 때문에 켜지지 않을 수 있습니다.
     앱 정보 › 오른쪽 위 ⋮ › **제한된 설정 허용** 을 누른 뒤 다시 켜세요.
3. 고정할 앱을 열고 **볼륨 내리기 버튼을 빠르게 세 번** 누릅니다. (또는 메인 화면에서 *앱 선택해서 시작*)
4. 반투명한 설정 화면에서 터치를 막을 영역을 드래그로 지정합니다.
   - 빈 곳 드래그: 새 영역 / 영역 드래그: 이동 / 흰 점: 크기 조절 / 빨간 ×: 삭제
5. 아래 **옵션** 에서 터치·볼륨 버튼·시간 제한을 설정하고 **시작** 을 누릅니다. 처음이면 암호를 정합니다.
6. 종료: 볼륨 내리기 세 번 → 암호 입력 → **종료** (또는 **재개** 로 영역/옵션만 수정)

### 강력 잠금 (선택, 기기 소유자 모드)

기기에 Google 계정 등 **계정이 하나도 없는 상태**에서 PC로 아래 명령을 실행합니다.

```bash
adb shell dpm set-device-owner com.guidedaccess.aos/.AdminReceiver
```

이후 사용법 유도를 시작하면 시스템 LockTask가 걸려 홈/최근 앱 버튼과 제스처가 동작하지 않습니다.
해제는 앱 메인 화면의 **기기 소유자 해제** 버튼으로 할 수 있습니다.

### 암호를 잊어버렸다면

안전 모드로 부팅하면 서드파티 접근성 서비스가 꺼지므로 빠져나올 수 있습니다.
(기본 설정에서는 재시작만 해도 해제됩니다.)

## 동작 원리

- `GuidedAccessService` (AccessibilityService)
  - `TYPE_WINDOW_STATE_CHANGED` 이벤트로 현재 화면의 앱 패키지만 확인합니다. **화면 내용은 읽지 않습니다**
    (`canRetrieveWindowContent=false`).
  - 대상 앱이 아닌 앱/홈 화면이 뜨면 '사용법 유도 사용 중' 화면으로 즉시 가리고 대상 앱을 다시 실행합니다.
    키보드, 권한 요청 창, 공유 시트, Google 로그인 화면처럼 앱이 잠깐 띄우는 시스템 화면은 허용합니다.
  - `TYPE_ACCESSIBILITY_OVERLAY` 창으로 차단 영역·암호 키패드·설정 화면을 그립니다.
    (별도의 '다른 앱 위에 표시' 권한이 필요 없습니다.)
  - `onKeyEvent` 로 볼륨 키를 감지·차단합니다.
- 기기 소유자인 경우 `DevicePolicyManager.setLockTaskPackages` + `ActivityOptions.setLockTaskEnabled` 로
  대상 앱을 LockTask 모드로 실행하고, 종료 시 허용 목록을 비워 해제합니다.

## 한계

- 기기 소유자가 아니면 홈/최근 앱 제스처 자체를 막을 수는 없고, **나가는 즉시 되돌리는** 방식입니다.
  (아주 잠깐 홈 화면이 보일 수 있지만 그 위를 덮는 차단 화면 때문에 조작은 불가능합니다.)
- 전원 버튼은 막을 수 없습니다. (iOS도 동일하게 화면 잠금은 가능)
- 차단 영역은 화면 비율로 저장되므로 화면을 회전하면 위치가 비율대로 옮겨집니다.
- Google Play에 배포하려면 접근성 API 사용 목적을 신고해야 합니다.

## 빌드

- Android Studio에서 열거나, 명령줄에서:

```bash
./gradlew assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

- GitHub에 push하면 Actions(`.github/workflows/build.yml`)가 디버그 APK를 빌드해 아티팩트로 올립니다.
- 최소 Android 8.0 (API 26), 타깃 Android 15 (API 35), Kotlin.

## 프로젝트 구조

```
app/src/main/java/com/guidedaccess/aos/
├── GuidedAccessService.kt   # 상태 관리(IDLE/SETUP/ACTIVE), 앱 이탈 방지, 볼륨 키, 시간 제한, LockTask
├── MainActivity.kt          # 서비스 상태, 암호 설정, 앱 선택, 설정
├── Prefs.kt                 # 암호 해시, 앱별 설정(AppConfig), 세션 저장
├── AdminReceiver.kt         # 기기 소유자(선택)
└── overlay/
    ├── OverlayHost.kt       # 접근성 오버레이 창 추가/제거/회전 대응
    ├── SetupOverlay.kt      # 영역 지정 + 옵션 화면
    ├── AreaViews.kt         # 영역 편집기, 차단 영역 뷰
    ├── PinOverlay.kt        # 숫자 키패드 암호 입력/생성
    └── MessageOverlay.kt    # '사용 중', '시간 종료' 화면
```
